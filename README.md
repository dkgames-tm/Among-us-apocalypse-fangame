# Among Us Fangame

A fan-made game inspired by **Among Us**, where your goal is to survive against Seekers by killing them.

## 🎮 About the Game

Survive against the Seekers and fight back by eliminating them before they get you. Stay alive for as long as you can!

This fangame uses original assets from Among Us.

## 📥 Downloads

You can download the game from the releases/download page:

- **Windows:** `.exe`
- **Android:** `.apk`

Download the version compatible with your device and follow any installation instructions provided.

## 🕹️ Gameplay

- Survive against the Seekers.
- Kill the Seekers to stay alive.
- Try to survive as long as possible!

## 🛠️ Built With

- Godot Engine
- GDScript
